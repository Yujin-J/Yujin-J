## ST_CRM — 팀 프로젝트

고객·연락처·상담 정보를 관리하는 CRM에 AI 챗봇을 연결하는 프로젝트에 참여했습니다.

- **담당 기능:** GPT·Gemini 연동 및 Firebase 고객·상담 데이터 기반 챗봇 구현.
- **팀 협업 기록:** 저장소에 기능별 브랜치의 Pull Request와 병합 이력이 남아 있습니다.
- **구현 확인:** 현재 공개된 챗봇 코드는 Firebase 데이터를 읽어 질문과 함께 전달하며, Gemini 형식의 API 요청·응답을 사용합니다.
